Welcome

Welcome to the urine test strip reader system. This portal provides information about urine test strip analysis using colorimetry as a point-of-care technology. The system helps healthcare professionals obtain accurate and reliable urine analysis reports.

The system captures images of urine test strips using a Raspberry Pi camera inside a controlled illumination box. It analyses the colour changes on the reagent pads and generates digital reports for patients and clinicians.
